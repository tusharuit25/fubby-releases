# Fubby 0.1.4 Windows beta

**Fubby for Windows is here, as a beta.** It's brand new, so you may be one of the
first people to run it, and you may hit bugs. Please report them, so they can be
fixed in the next release.

- `fubby-0.1.4-x86_64-pc-windows-gnu.zip` is the download. It needs Windows 10 or
  later on an x86-64 PC, and isn't signed, so SmartScreen may warn you.
- `fubby-0.1.4-x86_64-pc-windows-gnu.zip.sha256` holds its SHA-256:
  `f87bb718421d510d19b8557bd8f302b3d65067362a0d2379e7578c15d5caa0ec`

To verify, install, uninstall, or report a problem, follow the
[Windows beta steps](../README.md#windows-beta) in the main README.
