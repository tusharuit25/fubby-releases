# Hello and expressions

Milestones: M1.

Print a greeting, declare variables and constants, and evaluate arithmetic.

## Run

With Fubby 0.1.0 on PATH, open a terminal in this folder:

```sh
fubby check hello.fab
fubby run hello.fab
fubby check basics.fab
fubby run basics.fab
```

## What to expect

Hello, Fubby!; the basics example prints 42.

## Try it

Change an input value in the example, rerun it, and compare the result. `fubby check` checks syntax/imports; execution checks runtime behavior.
