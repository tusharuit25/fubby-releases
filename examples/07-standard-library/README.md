# Strings, math, files, and time

Milestones: M7.

Transform strings, calculate numbers, and write/read a local text file.

## Run

With Fubby 0.3.0 on PATH, open a terminal in this folder:

```sh
fubby check milestone7.fab
fubby run milestone7.fab
```

## What to expect

FUBBY and other transformed values; file contents Milestone 7. Creates fubby-m7-test.txt in this folder.

## Try it

Change an input value in the example, rerun it, and compare the result. `fubby check` checks syntax/imports; execution checks runtime behavior.
