# Bela tasks and channels

Milestones: M15.

Spawn a task with input, join its result, and send a message through a bounded channel.

## Run

With Fubby 0.1.0 on PATH, open a terminal in this folder:

```sh
fubby check bela.fab
fubby run bela.fab
```

## What to expect

A task status (timing-dependent), 144, and ready.

## Try it

Change an input value in the example, rerun it, and compare the result. `fubby check` checks syntax/imports; execution checks runtime behavior.
