# Types and control flow

Milestones: M2.

Use typed values, conditions, while loops, and ranges.

## Run

With Fubby 0.1.0 on PATH, open a terminal in this folder:

```sh
fubby check milestone2.fab
fubby run milestone2.fab
```

## What to expect

A readiness message, while values 0–2, and range values 1–5.

## Try it

Change an input value in the example, rerun it, and compare the result. `fubby check` checks syntax/imports; execution checks runtime behavior.
