# Runtime execution

Milestones: M9–10, M18.

Accumulate a range using compound assignment. These milestones also hardened the runtime rather than adding a separate application API.

## Run

With Fubby 0.1.0 on PATH, open a terminal in this folder:

```sh
fubby check milestone10.fab
fubby run milestone10.fab
```

## What to expect

500500 and RUNTIME OK.

## Try it

Change an input value in the example, rerun it, and compare the result. `fubby check` checks syntax/imports; execution checks runtime behavior.
