# Collections, JSON, encoding, and environment

Milestones: M11.

Explore Unicode strings, list helpers, maps, JSON, regex, encoding, UTC dates, random values, and environment information.

## Run

With Fubby 0.3.0 on PATH, open a terminal in this folder:

```sh
fubby check milestone11.fab
fubby run milestone11.fab
```

## What to expect

JSON round trips, decoded text, leap-year checks, and true for the caught expected error. Platform and environment output varies.

## Try it

Change an input value in the example, rerun it, and compare the result. `fubby check` checks syntax/imports; execution checks runtime behavior.
