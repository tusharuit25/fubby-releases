# Inheritance and interfaces

Milestones: M5.

Implement an interface, override a method, and call the parent implementation.

## Run

With Fubby 0.3.0 on PATH, open a terminal in this folder:

```sh
fubby check milestone5.fab
fubby run milestone5.fab
```

## What to expect

Account: Fubby / savings, then 250.

## Try it

Change an input value in the example, rerun it, and compare the result. `fubby check` checks syntax/imports; execution checks runtime behavior.
