# Collections, imports, and exceptions

Milestones: M6.

Mutate lists and maps, import a local helper, and catch failures.

## Run

With Fubby 0.1.0 on PATH, open a terminal in this folder:

```sh
fubby check milestone6.fab
fubby run milestone6.fab
fubby check milestone6_complete.fab
fubby run milestone6_complete.fab
```

## What to expect

List total 100; map values and a greeting; caught missing key.

## Try it

Change an input value in the example, rerun it, and compare the result. `fubby check` checks syntax/imports; execution checks runtime behavior.
